# Development Guide

## Prerequisites

- Go dengan versi yang sesuai dengan go.mod.
- Database yang digunakan aplikasi.
- Git.
- Docker, jika diperlukan untuk lingkungan pengembangan.

## Setup

### 1. Clone Repository

### 2. Configure Environment

Salin .env.example jika aplikasi menggunakan file .env.

### 3. Install Dependencies

```bash
go mod download
```
