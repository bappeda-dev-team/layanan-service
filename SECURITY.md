# Security Policy

## Reporting a Vulnerability

Jelaskan mekanisme pelaporan kerentanan secara privat.

## Security Guidelines

- Jangan menyimpan credential di repository.
- Validasi input dari pengguna.
- Jangan mengekspos detail internal melalui error response.
- Hindari mencatat token dan informasi sensitif ke log.
- Terapkan autentikasi dan otorisasi sesuai kebutuhan.
- Gunakan konfigurasi yang sesuai untuk lingkungan produksi.
